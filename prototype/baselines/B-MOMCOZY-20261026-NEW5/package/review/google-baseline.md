# Google 风格母婴 APP · 无 Dock 对话版

版本：2026-10-25；目标：移动 APP 的 Web 验证原型。首页只有对话流与输入区；顶部进入二级页面。无底部导航，无角色，无粉色。

## 页面与入口

P1 对话：首页；右上角记录按钮 → P2；头像/宝宝按钮 → 宝宝切换；菜单 → 侧栏。左滑 → P2，右滑 → 侧栏。P2/P3 滑动或顶部返回 → P1。输入区的 + 打开记录与工具面板。
P2 记录：今日喂养/睡眠/尿布、最近体重、分类筛选、时间线、详情、编辑、删除和撤销。
P3 资料：个人、宝宝、需求。建档分四步，最后解释按需权限。
P4 底部面板：记录编辑、媒体、模板、成长、偏好。Esc/关闭恢复上下文。背景由原生 dialog 阻止操作。

## 逐事件契约

| T-ID | 触发 → 状态 | 反馈 / 副作用 | 中断与恢复 |
|---|---|---|---|
| T-navigation | 顶部/侧栏/滑动 → 页面 | 页面标题、淡入/位移；保留对话与记录草稿 | 可立即返回，无底部 Dock |
| T-panel | 功能入口 → dialog | 遮罩、底部上移、焦点转移 | Esc/关闭，归还焦点；草稿保留 |
| T-input/T-voice | 按住 → 授权/聆听 → 确认文字 | 状态文本；上滑取消；不伪造识别 | 失焦/关闭取消；旧回调失效 |
| T-chat | 发送 → 等待 → 本地示例 | 输入清空、等待文本、停止按钮 | 停止定时任务；不宣称模型推理 |
| T-record | 创建 → 缺项 → 完整草稿 | 内嵌补充选项、确认摘要 | 修改/取消，不自动落库 |
| T-save | 确认 → 保存 → 成功/失败 | localStorage 成功后才展示成功 | 锁定提交值；失败保留；重试 |
| T-edit | 修改 → 草稿更新 | 字段回填与更新提示 | 关闭暂存，仍须确认保存 |
| T-schema | 创建模板 → 字段 → 保存 | 字段类型/选项/单位即时反馈 | 校验失败留在表单；模板写入后方成功 |
| T-delete | 删除 → 撤销窗口 | 持久移除；10 秒内可撤销 | 恢复真实记录，失败明确提示 |
| T-proactive | 稍后/关闭/恢复 | 当前任务状态持久化 | 页面打开时检查提醒；不声称后台推送 |

所有动效的起始偏移为 0，输入不等待动效结束；reduced-motion 关闭非必要动画。T-chat 的延迟属于标注的本地演示；保存无强制展示延迟，验证面板可显式注入延迟/失败。日志仅事件与状态，不记录用户内容。

## 独立挑战与修复

独立审查实际发现自定义模板与“其他”同时 selected（P1），以及亲喂侧别回填丢失（P2）。均已修复。另补测动态数字/选择值在关闭面板后恢复、双击只写一次、照片加载、麦克风拒绝与大文本面板。报告见 review/google-results.json、review/google-edge-results.json。

严格目标仍有明确差距：无官方 SDK 弹簧/图标；无真实 AI 流；无已验证的阶段与健康规则；真机语音/键盘待验收。不可把这些归为已完成的生产能力。
