# Material 动效与背景 UI · 执行规范 V1.1

更新：2026-10-25。目标：Material 3 Expressive 应用设计；HTML 演示用于评审，后续映射 Flutter / Compose。不是完整 Pixel OS 复刻。

## 1. 结论与边界

采用「语义色表面 + 空间弹簧 + 效果轨道 + 真实业务状态」。母婴场景只用于说明喂养记录与助手回应，不改动已有产品工程或 IP。品牌关键色可以映射 primary；普通背景保持低强调，不能把所有容器都染成品牌色。

证据分类：O 官方；P Pixel 官方展示参考；D 项目设计规则；A Web 适配。以下组件映射、时间建议、演示配色均为 D/A，不能作为 Google 强制规格。

## 3. 背景 UI 与层级

角色决定用途，不能用亮度推测绝对 z 轴顺序；暗色主题独立映射，不反转整页。下表用途是 D，角色模型源自 S3/S4。

|层/部件|建议角色|行为|避免|
|---|---|---|---|
|页面底色|surface|保持稳定，支撑阅读|无限漂浮渐变、纹理干扰|
|低强调内容分区|surfaceContainerLow|区分长页面段落|每一行都用大卡片|
|常规卡片/导航区域|surfaceContainer|按语义分组|把所有卡片同时抬高|
|弹层/较强分区|surfaceContainerHigh|前景面板需清晰边界|误认为色阶等于海拔|
|输入区/局部强调|surfaceContainerHighest|与正文区分，保留标签|只靠底色表达错误|
|独立低层表面|surfaceContainerLowest|用于需要清楚分隔的独立区域|固定等于纯白|
|主动作|primary + onPrimary|一屏明确主要操作|多个同等强度主按钮|
|选中/辅助动作|primaryContainer + onPrimaryContainer|文本或图标同时标注选中|仅变色而不更新语义|
|次要文字/边界|onSurfaceVariant / outlineVariant|正文用 onSurface|低对比度浅灰正文|
|错误|error / errorContainer 对应前景|就近、持续显示原因与恢复动作|只弹出一闪而过的提示|
|遮罩|scrim|模态打开时背景不可操作|模糊当作模态语义|
|临时反馈|inverseSurface + inverseOnSurface|简短结果与撤销|覆盖输入区或主操作|

页面内部默认不使用玻璃材质。Pixel 通知背景模糊另列为 P：可以在展示中单独比较，不自动应用到母婴 App 所有卡片。演示采用固定浅紫灰色表面，属于 A，不是壁纸动态取色。

滚动：顶栏与内容职责分开，输入区与底导航按真实高度预留空间。键盘出现时保证焦点字段和提交按钮可见。弹层拥有自己的滚动区域，页面背景锁定。安全区、横屏、200% 文本、长名字必须验证。

## 4. 动效基础

|轨道|用于|默认策略|
|---|---|---|
|Spatial|位置、大小、旋转、形状|弹簧；允许受控超调；文本不跟随容器缩放|
|Effects|透明度、颜色|无超调；alpha 限制 0–1|
|直接操控|拖拽、滑杆|跟随手指，释放后再结算，不让数值滞后|
|过程|加载、录音、上传、AI|绑定真实状态，不依靠动画完成改变业务事实|

沿用 Skill 固定 S7 基线：expressive spatial fast (ζ=.6,k=800)、default (.8,380)、slow (.8,200)；effects fast (1,3800)、default (1,1600)、slow (1,800)。质量按 1。不是毫秒值，不能把 k 填入 duration。交互绑定是 D。

对不支持物理系统的平台可做显式 A 适配。不要用通用 ease-out 冒充弹簧。演示的形状循环是原创 CSS 近似，不是官方 LoadingIndicator 几何。

## 5. 逐项目录

|ID|触发与状态|运动/背景|中断与结束|减少动态效果|
|---|---|---|---|---|
|M01 按钮|按下→释放/取消|fast spatial 轻微形变，fast effects 状态层|pointercancel 清按压态；执行不等待动画|取消形变，保留焦点/状态层|
|M02 标签|未选→已选|选中容器与标记变化；不挤压标签|快速反选从当前状态重定向|直接切换标记|
|M03 开关|关↔开|滑块 fast spatial；背景 effects|业务状态立即更新，失败回滚|直接定位|
|M04 滑杆|开始拖动→数值→释放|手指直接驱动，气泡局部出现|pointercancel 停止拖拽，保留有效值|静态数值反馈|
|M05 今日卡片|折叠↔展开|default spatial 高度；内容独立排版|连点反向，不丢速度；折叠禁焦点进入隐藏内容|立即布局|
|M06 页面切换|列表→详情→返回|同对象可共享容器；无同一性则淡入/淡出|保留路由栈与列表位置；新标题接焦点|无大位移，直接显示|
|M07 同级内容|标签/导航切换|选中指示器与内容分离|快速换页只显示最新目标；保留各页状态|直接切换|
|M08 底部弹层|关闭→打开→关闭|slow/default spatial + effects 遮罩|背景 inert，Esc/返回关闭，焦点返回触发器|直接打开/关闭|
|M09 菜单/对话框|触发→决策/取消|锚点或局部展开，不全屏飞入|键盘移动、关闭恢复焦点|静态出现|
|M10 列表增删|确认成功→插入/移除|稳定 ID，邻项重排|删除以响应为准或明确乐观回滚|直接更新，播报结果|
|M11 下拉刷新|拉动→过阈值→刷新|先跟手，再进入过程|一次请求；取消回到原列表|保留按钮替代手势|
|M12 表单校验|编辑→非法→修正|字段周边错误文字，布局连续|保留输入，焦点到首个错误|不摇晃，持久文字|
|M13 短加载|pending→完成/失败|小范围不定形态循环|实际响应结束；后台停止装饰|静态“处理中”|
|M14 上传|选图→上传→处理→结果|真实字节百分比；处理单独标注|取消 abort + 过期响应隔离|静态阶段/真实数字|
|M15 语音|请求权限→录音→识别→结果|波形来自音量，角色状态跟随|松手/取消释放资源；拒绝有替代输入|静态录音状态与计时|
|M16 AI|提交→等待→流式→完成|响应区域局部反馈|停止保留部分内容；不强制滚到底|稳定文本与阶段标签|
|M17 保存|校验→saving→saved/failed|按钮尺寸不变，成功后反馈|持久化确认后才成功；失败可重试|直接状态更新|
|M18 提示|成功/撤销→恢复阅读|inverse 表面，避开键盘|可操作提示留足时间；失败不只用 snackbar|静态出现|
|M19 主题切换|浅色↔深色|全语义角色同时切换|不触发所有控件弹跳|立即更新|
|M20 图表|筛选→数据变化|坐标稳定，强调选中数据|不动画伪造中间测量值|直接重绘|

演示已实现 M01/M02/M05/M06（局部返回视图）/M08/M13（模拟）/M17/M19 和表面角色比较。其余为可执行设计规则，未宣称均有演示实现。拖拽底部弹层、原生预测返回、设备触感、真实语音/AI/上传均不在本 HTML 实现范围。

## 6. 母婴 App 的应用规则（设计推导）

首次引导：每一步聚焦一组信息，下一步出现不遮挡已选内容。首页：今日卡片展开不挤压底部输入区。快速记录：喂养类型用单组选项，字段随选择更新，避免整个表单反复弹出。睡眠计时：时长由开始/结束时间计算，退出页面不停止真实计时。尿布记录：选项有明确选中态，保存后回到原上下文。助手仅在记录成功后确认；没有数据不能生成“趋势正常”等结论。

这份交付只演示一条记录的本地存储机制，不替代三类记录的完整业务规格，不修改既有 App。

## 7. 单条实施契约模板

每一项提供：ID；页面/组件；触发动作；起止状态；前置条件；属性与坐标原点；空间/效果轨道；来源与版本；取消/反向/重复点击；业务完成事件；焦点/读屏；减少动画；失败回退；测试证据。

示例 M17：提交合法奶量→本地存储写入→成功。错误留在表单；重试使用同一编辑内容；重复点击禁用。演示的“模拟处理”与实际本地保存明确分离，不为展示加载人为延迟保存。

## 8. 平台落地与验收

Compose：核对安装版本，优先官方 MotionScheme 与组件，系统返回/触感单独验收。Flutter：useMaterial3 不等于全套 Expressive；适配弹簧时阻尼系数 c=2ζ√(km)，与阻尼比不同。HTML：语义控件、原生 dialog、可中断数值弹簧；不声称原生系统能力。

发布前需验证：快速连点；中途反向；减少动画实时开启；后台切换；失败/取消/重试；刷新后保存；键盘与焦点；窄屏；深色；200% 字体；文字与背景对比。未测项目必须记为未测。

## 9. 第二挑战检查

挑战视角：这个演示是否只是好看的着色？检验规则是运动是否解释状态、状态是否来自真实操作。是否用旧 token 冒充最新？必须保留 S7 历史标记。是否做了假的 AI/保存？模拟过程显式标识，保存另用真实 localStorage。是否全部已实现？使用第 5 节范围清单，不能将规范条目等同于完成代码。独立审查结果与实测记录随交付追加。
