# New5 欢迎页整合微调

## 当前生效：Material 3 日期面板

生日入口改为内嵌日期选择面板：色调标题区、月份导航、周历网格、圆形选中状态、今天描边和未来日期禁用。移除拟物装订环与纸页阴影，保留编辑图标调用原生日期选择、日期持久化与流式提示。使用项目已锁定tokens的Web适配，不宣称原生SDK或Google认证。证据：review/material-calendar/verification.json。


## 当前生效：居中刻度与确认卡片

孕周新输入默认38周；已有草稿保留原值。孕周与天数均使用固定中心指示器，邻近刻度横向移动，支持拖动、滚轮、点击邻近数值及方向键/Home/End。两端值也居中显示，初始不铺满整个28–42范围。保留原始范围、额外天数条件与动画。确认页采用与选项一致的独立圆角描边、底部阴影、图标卡片，保留编辑入口。证据：review/centered-ruler/verification.json。


## 当前生效：流式节奏与离散滑块

流式速度由中英文字符、标点/换行、起步/收尾及作者文案语气决定；欢迎略温和，提醒略放慢，不识别或推断用户情绪。onboarding与主页欢迎共用节奏规则。孕周与额外天数改为Material 3风格适配：填充轨道、离散点、竖向手柄和可见键盘焦点。天数展开300ms、收起220ms，使用缓出曲线；反向切换取消旧动画，收起立即移出键盘交互，减少动态直接切换。参数为项目适配值。证据：review/motion-rhythm/verification.json。


## 当前生效：阶段、生日入口与出生孕周

流程：欢迎 → 用户称呼 → 宝宝阶段 → 宝宝名称 → 性别 → 生日 → 出生孕周 → 关注事项 → 核对 → 完成 → 主页。等待见面尚未开放，流式提示并禁用继续；阶段和性别移除暂不填写。生日卡直接开启原生日期选择器。出生孕周28–42周；按用户确认，小于37周显示额外0–6天，37周及以上隐藏并清零天数。该字段为出生时孕周；不进行医疗建议或校正月龄推断。旧草稿补经孕周页面，旧等待见面草稿返回阶段。关注选项移除说明文字。欢迎语仅使用称呼、宝宝名和一个关注问题，不复述生日及资料清单。证据：review/gestation-flow/verification.json。


## 当前生效：onboarding 图标与辅助文本清理

性别选项直接复用展示头像组件及配色；生日页移除选填标记和用途备注，但仍允许留空；核对页移除记录保留备注，将修改文字替换为有辅助技术名称的编辑图标；完成页移除保存小字和确认勾选图标，保留AI气泡、形象与进入主页。证据：review/onboarding-cleanup/verification.json。


## 当前生效：主页个性化欢迎

完成核对保存并点击进入主页后，首条助手消息按已保存的用户称呼、宝宝姓名/阶段/生日和关注事项生成欢迎语，并逐字呈现。未填写内容使用中性文案；以开放问题引导对话。欢迎全文先保存到本机对话，刷新显示完整消息，不重复发送。用户开始输入发送或离开主页时完成当前欢迎文字，减少动态直接显示全文。此为本地模板个性化呈现，并非模型接口。两张姓名输入框恢复对应用户/宝宝前置图标，保留单一占位提示和原风格。

证据：review/home-welcome/verification.json；测试：tests/home-welcome.cjs。此前章节为迭代历史。
