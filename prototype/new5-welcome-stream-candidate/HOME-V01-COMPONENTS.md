# V01 主页组件拆解

| 参考组件 | 本轮落实 | 行为与范围 |
|---|---|---|
| 顶部导航 | 菜单、Momcozy双行标识、趋势、记录、宝宝胶囊 | 沿用原入口；次级页面不改 |
| 陪伴欢迎区 | 薄荷有机背景、现有3D角色、白色气泡 | 保留姓名和流式个性化消息；不替换角色 |
| 今日提示卡 | 日期、真实记录概况、展开箭头 | 沿用折叠摘要和原始记录入口，不照搬困倦推断 |
| 对话列表 | 助手头像+浅灰蓝气泡，用户浅蓝气泡 | 沿用历史消息、记录核对、模拟分析标识 |
| 快捷操作 | 白色托盘、三枚柔和彩色图标底座 | 记一笔/听哭闹/看便便，入口语义不变 |
| 输入栏 | 加号、圆润文字框、发送、语音切换 | 默认文字以对应参考；原长按语音仍可切换 |
| 侧栏展开态 | 本轮不改 | 保留当前菜单 |
| 语音分析处理中 | 本轮不改 | 保留既有状态机，后续逐步优化 |

参考图是视觉依据，具体色值/尺寸为项目适配；图中的医疗推断与示例记录不作为真实数据导入。

## 第二轮批注 · 2026-10-26
- 消息列表移除双方头像，保留文本、媒体、核对/保存与处理状态卡片。欢迎文字取消白色气泡。
- 今日摘要随聊天滚动吸顶并紧凑显示，仍可展开查看；主页不再生成主动提醒卡，不修改用户既有提醒偏好。
- 录制音频与上传音频采用相同播放/暂停波形条；波形为装饰，时长/播放状态来自实际音频事件。预览过期明确提示重新添加。
- 照片/录音发送后以原形象和有机波浪背景显示本机模拟处理，可中断，错误保留重试入口；不虚构云上传进度或分析结论。
- 录音过程背景按计时0–10秒由黄变绿，保留30秒限制。减少动态效果关闭波浪/旋转/波形循环。
