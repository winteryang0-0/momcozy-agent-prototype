Chrome headless，390×844：实际运动变化；动画时轴 0/5/5.75/6.5/10/10.75/11.5/15 秒换色采样；5 秒 alternate 空间轨道；真实菜单打开/关闭后暂停恢复；路由属性切换；document.hidden 模拟；两种应用减少动态 class；系统 reduced-motion 媒体模拟。长内容滚动后背景矩形不变，pointer-events 为 none，输入点击、焦点及草稿输入正常。

同一页面禁用/启用新增 CSS，对比顶部、滚动区、欢迎内容、角色容器、角色 canvas、输入区、输入框、快捷入口共八个元素的矩形、字体、内边距、外边距、动画及底色（仅滚动区底色允许不同），通过。截图已查看。独立只读挑战未发现阻断性问题。

原有 tests/compact-home.cjs 通过：三个喂养类型切换、刻度键盘控制、120 ml 本地保存，无运行时异常。冻结 New5 与 R27 完整性检查通过。
