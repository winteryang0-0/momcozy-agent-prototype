## 当前生效：居中刻度与确认卡片

孕周新输入默认38周；已有草稿保留原值。孕周与天数均使用固定中心指示器，邻近刻度横向移动，支持拖动、滚轮、点击邻近数值及方向键/Home/End。两端值也居中显示，初始不铺满整个28–42范围。保留原始范围、额外天数条件与动画。确认页采用与选项一致的独立圆角描边、底部阴影、图标卡片，保留编辑入口。证据：review/centered-ruler/verification.json。


## 当前生效：流式节奏与离散滑块

流式速度由中英文字符、标点/换行、起步/收尾及作者文案语气决定；欢迎略温和，提醒略放慢，不识别或推断用户情绪。onboarding与主页欢迎共用节奏规则。孕周与额外天数改为Material 3风格适配：填充轨道、离散点、竖向手柄和可见键盘焦点。天数展开300ms、收起220ms，使用缓出曲线；反向切换取消旧动画，收起立即移出键盘交互，减少动态直接切换。参数为项目适配值。证据：review/motion-rhythm/verification.json。


## 当前生效：阶段、生日入口与出生孕周

流程：欢迎 → 用户称呼 → 宝宝阶段 → 宝宝名称 → 性别 → 生日 → 出生孕周 → 关注事项 → 核对 → 完成 → 主页。等待见面尚未开放，流式提示并禁用继续；阶段和性别移除暂不填写。生日卡直接开启原生日期选择器。出生孕周28–42周；按用户确认，小于37周显示额外0–6天，37周及以上隐藏并清零天数。该字段为出生时孕周；不进行医疗建议或校正月龄推断。旧草稿补经孕周页面，旧等待见面草稿返回阶段。关注选项移除说明文字。欢迎语仅使用称呼、宝宝名和一个关注问题，不复述生日及资料清单。证据：review/gestation-flow/verification.json。


## 当前生效：主页个性化欢迎

完成核对保存并点击进入主页后，首条助手消息按已保存的用户称呼、宝宝姓名/阶段/生日和关注事项生成欢迎语，并逐字呈现。未填写内容使用中性文案；以开放问题引导对话。欢迎全文先保存到本机对话，刷新显示完整消息，不重复发送。用户开始输入发送或离开主页时完成当前欢迎文字，减少动态直接显示全文。此为本地模板个性化呈现，并非模型接口。两张姓名输入框恢复对应用户/宝宝前置图标，保留单一占位提示和原风格。

证据：review/home-welcome/verification.json；测试：tests/home-welcome.cjs。此前章节为迭代历史。


## 当前生效：输入与流式反馈微调

本节覆盖此前“保留首笔记录”的路径。当前流程：欢迎 → 用户称呼 → 宝宝小名 → 阶段 → 性别 → 生日（等待见面省略）→ 关注事项 → 看一眼核对状态 → 确认保存 → 进入主页。首笔记录不再纳入 onboarding；已有记录保留，旧引导中的未提交记录不随资料保存。

姓名页只显示带灰色占位文字的输入框，保留辅助技术标签。所有页面AI文字采用预设文字流式呈现；阶段、性别、关注选项触发各自反馈，取消关注也有对应反馈。新选择取消旧流式，快速切页不串字，减少动态直接显示全文。移除选中反馈小字。生日卡采用Material语义颜色、圆角、页眉与纸张层次，实时显示日期。

本轮证据：review/flow-polish/verification.json；tests/flow-polish.cjs。基础风格与原始New5基线不变。历史验证仅对应当时版本。


## 当前生效：2026-10-26 onboarding 流程精简

沿用 New5 基础风格。当前路径：欢迎 → 你的称呼 → 宝宝小名 → 宝宝阶段 → 性别 → 生日 → 关注内容 → 首笔记录类型 → 记录填写 → 核对保存 → 已保存 → 首页。等待见面分支省略生日和首笔记录，在关注内容后直接核对。

- 欢迎语保持20px、自然分段和流式呈现，调整为650字重、左对齐。
- 第二页仅输入用户称呼，第三页仅输入宝宝小名；输入卡沿用蓝色选中卡的底色、轮廓、图标与勾选。姓名仍选填，不再选择用户角色，已有角色数据保留。
- 移除恢复引导中的“继续使用现有资料”、全流程底部跳过入口、继续按钮右箭头与角色旁对话小图标；保留顶部返回。
- 移除能力介绍、权限介绍和开始方式页。关注内容可不选继续；阶段页内“暂不填写”是阶段选择，保留。
- 生日预览与日期输入实时同步，清空恢复占位，未来日期阻止继续。
- 非等待见面分支保留首笔记录填写与核对保存，最终提交前检查缺失记录。返回、刷新保留草稿；旧步骤1迁移到欢迎，7/8/9迁移到关注内容。

## 页面与状态

P00 欢迎 → P01 流程说明 → P02 关于你 → P03 宝宝阶段 → P04 小名/性别 → P05 生日 → P06 关注内容 → P07 能力说明 → P08 权限说明 → P09 开始方式 → P10 首次记录类型 → P11 数值/时间 → P12 核对 → P13 已保存 → 首页。

- 等待见面：跳过生日；仅允许先看看主页，不允许进入宝宝记录。
- P02/03/04/05/06 可跳过；P10/11 可暂不记录。没有选中的必需选择时继续禁用，旁边仍有明确跳过入口。
- 权限按用途解释，用到时才向浏览器申请；不会在引导里连续弹授权。
- 空数值不等于滑动尺的展示位置。点选/滑动后才产生值，核对页提交后才新增记录。
- 顶部返回使用真实访问栈。关闭/刷新保留步骤和输入；再次进入恢复。
- 设置最下方“重置首次引导”先解释范围：只重置引导进度，保留宝宝、已有记录和偏好；最后核对才应用资料修改。

## 动效 D（不是截图测量值）

- 选择：Material fast spatial 按压弹簧 ζ=.6 / k=800；颜色160ms。释放与业务选择独立。
- 页面内容：default spatial ζ=.8 / k=380，透明度160ms；只对角色/内容区入场，不移动固定 CTA。
- 进度：从上一屏比例到当前比例，240ms cubic-bezier(.2,0,0,1)；比例是填写进度，不是上传/AI进度。
- 取消/快速返回：旧 DOM 动画不承载业务；新状态立即可操作。
- 减少动态：无位移或循环，直接显示稳定结果与文本；不影响真实保存。

实现：assets/conversation.js、onboarding.css、material-motion.js。验证：tests/onboarding-flow.cjs；独立挑战：review/onboarding-challenge.json。真实手机键盘与源 App 时间参数未验证。
