HOME-1.1 · Today 卡片微调候选 26
日期：2026-10-21。设计状态：draft，未冻结。

一、授权与范围
用户要求移除 Today 卡「查看依据」弹窗，将三枚页面指示点置于卡片底部居中，移除与收起控件冲突的左右切换箭头，并让三条提醒循环滑动；随后补充要求侧栏暂时移除智能体服务入口与「照护空间」等冗余文字。对应 sources/today-card-26-requirements.json 的 R26-01～06。R17-03 和 R25-01 中有关依据入口和左右箭头的呈现规则、R24-03 中侧栏服务展示规则被替换；四条 hash 路由、常驻照护功能和连续任务逻辑沿用 R25。

二、页面、控件、功能与交互
- PAGE-home / HOME-advice、HOME-today-expanded：共享 adviceWidget、adviceControls 与 changeAdvice。标题、简短说明及三枚页码点位于同一卡内，页码点在底部居中。点选可直接选页；横向滑动和键盘方向键按三页循环，纵向触摸不切页。卡片不渲染依据弹窗入口和左右箭头。
- PAGE-home / HOME-today-compact：对话后折叠条仍可恢复完整 Today 卡，展开态顶部收起；再次展开保留当前页。assets/today-card-26.css 沿用莓色留白 token，覆盖夜间、短屏和减少动效。
- PAGE-home / NAV-sidebar-*：侧栏仅保留「我的」「宝宝」「当日记录」与关闭控件；去掉标题、服务分组、推荐排序、附加说明和服务入口。对话常驻照护功能与记录页新建入口仍可使用。
- PAGE-home / CHAT-care、CHAT-task、CHAT-record：每次明确触发生成新 taskId；先记住旧表单草稿并暂停旧卡，再创建前台卡。旧卡可承接到新卡，来源卡写入 resumedBy 并变只读。
- 媒体任务切换时释放麦克风/相机、素材 URL、整理与播报计时器；异步采集、播报和迟到文字意图校验任务或操作代次，不能修改后开的任务，也不能打断用户随后在现有卡片中的采集或填写。恢复旧媒体任务提示重新采集。
- 记录保存使用每张卡独立的计时器与固定 requestId/recordId；切卡后回执更新原卡。刷新或切换会话时，将未回执的保存显示为待核对。历史卡核对或重试沿用原请求，成功写入按 recordId 去重。失败草稿修改后继续使用同一请求。
- 首次录入、妈妈与宝宝数值范围、二级弹窗动效和记录页新建入口沿用上一候选；侧栏服务排序随服务入口暂时移除。

三、构建与验证
- index.html 与 assets/ 为相对资源版；build-standalone.cjs 生成可双击的 Momcozy-final.html，包含本轮 CSS。build-manifest.cjs 生成文件摘要。
- design.json 将 R26-01～06 映射到 PAGE-home、Today 与侧栏控件、动作、状态、流程及测试。历史来源和被替换的表现规则保留在账本中。
- delivery-review/today-card-26/qa-browser.cjs 在 Chrome headless 的 file:// 下操作单文件与模块版，覆盖页码点、双向循环、折叠恢复、触摸方向、Today 明暗与短屏状态，以及连续任务卡回归。截图绑定单文件散列，结果见 browser-evidence.json。
- 无合法经用户确认的 B-ID；静态内部引用校验和浏览器运行结果分别记录，不将脚本通过当成设计冻结或真机验收。

四、边界
记录保存、核对与媒体分析仍为原型流程。真实后台任务、服务端请求查询、跨设备幂等和医疗数据责任尚需接口及业务定义。真机触控、系统权限弹窗、软键盘和屏幕阅读器未在本轮验收。
