HOME-1.1 · 页面分类与 Today 缩略条候选 27
日期：2026-10-21。设计状态：draft，未冻结。

一、授权与范围
用户要求侧栏仅保留「我的」「宝宝」，移除当日记录；「宝宝」改为与「我的」一致的页面逻辑；Today 缩略状态的文字居中。对应 sources/profile-sections-27-requirements.json 的 R27-01～03。R24-02 中宝宝仅开资料弹窗，以及 R26-05／06 中侧栏保留当日记录的呈现方式由本轮替换。R26 完整快照保存于 prototype/versions/today-card-26/。

二、页面、控件、功能与交互
- PAGE-home / HOME-advice、HOME-today-expanded：共享 adviceWidget、adviceControls 与 changeAdvice。标题、简短说明及三枚页码点位于同一卡内，页码点在底部居中。点选可直接选页；横向滑动和键盘方向键按三页循环，纵向触摸不切页。卡片不渲染依据弹窗入口和左右箭头。
- PAGE-home / HOME-today-compact：对话后折叠条仍可恢复完整 Today 卡，展开态顶部收起；再次展开保留当前页。assets/today-card-26.css 沿用莓色留白 token，覆盖夜间、短屏和减少动效。
- PAGE-home / NAV-sidebar-*：侧栏仅保留「我的」「宝宝」与关闭控件；去掉当日记录直达入口、服务分组和附加说明。对话常驻照护功能仍可使用。
- PAGE-mine：保留个人资料与设备连接，新增妈妈当日记录及已有奶量趋势、身体与状态入口。
- PAGE-baby：新增 #/baby 作为与「我的」同层级的页面，包含顶部返回、宝宝概览、资料编辑、宝宝当日记录、喂养与睡眠、生长发育。资料编辑复用原表单和保存规则。
- PAGE-records：从我的或宝宝进入时预选相应对象；返回进入前页面。固定新建和右上二级功能菜单继续可用，菜单中宝宝入口进入宝宝页。
- PAGE-home / HOME-today-compact：折叠条使用两侧等宽轨道，让提醒标题相对整个条居中。整条点击恢复和动态标题切换保留。
- PAGE-home / CHAT-care、CHAT-task、CHAT-record：每次明确触发生成新 taskId；先记住旧表单草稿并暂停旧卡，再创建前台卡。旧卡可承接到新卡，来源卡写入 resumedBy 并变只读。
- 媒体任务切换时释放麦克风/相机、素材 URL、整理与播报计时器；异步采集、播报和迟到文字意图校验任务或操作代次，不能修改后开的任务，也不能打断用户随后在现有卡片中的采集或填写。恢复旧媒体任务提示重新采集。
- 记录保存使用每张卡独立的计时器与固定 requestId/recordId；切卡后回执更新原卡。刷新或切换会话时，将未回执的保存显示为待核对。历史卡核对或重试沿用原请求，成功写入按 recordId 去重。失败草稿修改后继续使用同一请求。
- 首次录入、妈妈与宝宝数值范围、二级弹窗动效和记录页新建入口沿用上一候选；侧栏服务排序随服务入口暂时移除。

三、构建与验证
- index.html 与 assets/ 为相对资源版；build-standalone.cjs 生成可双击的 Momcozy-final.html，包含 assets/profile-sections-27.css。build-manifest.cjs 生成文件摘要。
- design.json 将 R27-01～03 映射到页面、控件、动作、状态、流程及测试。历史来源和被替换的表现规则保留在账本中。
- delivery-review/profile-sections-27/qa-browser.cjs 在 Chrome headless 的 file:// 下操作单文件与模块版，覆盖双入口、资料校验与保存、记录返回、新建入口、Today 折叠居中及明暗短屏和桌面视口。截图绑定单文件散列，结果见 browser-evidence.json。
- 无合法经用户确认的 B-ID；静态内部引用校验和浏览器运行结果分别记录，不将脚本通过当成设计冻结或真机验收。

四、边界
记录保存、核对与媒体分析仍为原型流程。真实后台任务、服务端请求查询、跨设备幂等和医疗数据责任尚需接口及业务定义。真机触控、系统权限弹窗、软键盘和屏幕阅读器未在本轮验收。
