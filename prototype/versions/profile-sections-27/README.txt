日期：2026-10-21；状态：可交互候选，尚未冻结。

打开方式
1. 双击 Momcozy-final.html，可直接审阅内嵌样式、脚本和 AI 形象的单文件版。
2. 打开 index.html 时保留同目录 assets/；两种入口都支持 file:// 与 hash 路由。
3. 新浏览器资料首次进入四步信息录入；已有资料进入对话首页。左上角侧边栏仅提供「我的」「宝宝」两个入口。

本轮变化
- 侧栏移除「当日记录」直达入口；「我的」「宝宝」分别有对应记录入口，进入后记录页固定「新建记录」仍可用。
- 「宝宝」成为独立 #/baby 页面，使用与「我的」一致的顶部返回、资料概览及分组入口。宝宝资料编辑沿用已有表单，保存后更新概览；记录页返回进入前的页面。
- 对话后折叠的 Today 条内，当前提醒标题在缩略条整体中居中；点击整条恢复展开。
- 欢迎态与对话后展开态均移除「查看依据」入口和弹窗，也不再显示左右切换箭头；标题和简短提醒说明留在卡片中。
- 三枚可点选的页码点在卡片底部居中；点选、左右滑动和键盘方向键均可切换。第三条向左回到第一条，第一条向右进入第三条，纵向滚动不切页。
- 对话后的悬浮 Today 控件可收起或展开，重新展开保留当前提醒。
- 侧栏暂时移除智能体服务区、推荐排序及其入口，并去掉「照护空间」等说明文字。对话输入框上方的常驻照护功能和记录页新建入口保留。
- 输入框上方常驻「记一笔」「听哭闹」「看便便」。无论旧卡是否结束，再次点击同类或其他功能都会创建新的任务卡；单一文字意图遵循同一规则。
- 旧卡保留在对话时间线并显示暂停状态。点击旧卡可在新卡中继续；草稿字段沿用，原卡转为只读。录音、相机和照片素材切换后需要重新采集。
- 记录保存中也可开启下一任务。保存回执仍回到原卡；若刷新或切换会话使结果未明，可在原卡沿用同一请求编号核对，避免重复新增。
- 较早文字意图的迟到回复不会覆盖刚刚明确开启的任务，也不会中断你随后在现有卡片中的采集或填写。之前 R23/R24 的任务互斥规则已由本轮 R25-02/03 替换。
- 首页、当日记录、我的、宝宝和资料录入共五条页面路由；莓色留白视觉及记录页新建入口保留。

现有规则
- 妈妈年龄支持 18–50 岁，已分娩次数 0–6 次，宝宝出生孕周 37–50 周；均可留空，旧值超范围时要求用户修改或清空。
- 资料与照护记录保存在当前浏览器。功能卡片调用浏览器麦克风或相机时，权限仍由浏览器与操作系统决定。
- AI 识别、通用回复、输入栏语音转写、附件、设备同步及保存核对属于原型模拟，不提供诊断或真实服务端回执。
