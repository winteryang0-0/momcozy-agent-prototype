本轮由用户在 final-audit-13 审查之后授权：优化数据采集页图标；让交互任务按对话中的卡片流转；会话记一笔使用独立草稿并在会话卡片内展开；按 UI/UX 规范修正记一笔二级菜单；整合审查建议并输出终版 HTML。
授权原文、继承规则与 F01–F05 修复验收条件见 sources/revision-14-requirements.json。旧 sources/requirements.json 与 baselines/HOME-0.1 不改写。
“终版”指本次请求的可运行 HTML 输出。design.json 保持 draft；本轮修改授权不等于对尚未展示的新冻结基线作出批准。

二、当前信息架构
1. Dock 仅有 Today、momcozy AI、记录。Today 使用太阳，AI 使用与形象一致的图标；我的从 Today 顶部个人入口进入。
2. Today：照护背景 → 条件提醒 → 今日概况 → 三项快捷功能 → 条件任务恢复 → 最近记录 → AI 入口。
3. 记录：宝宝/妈妈分组，已有事件回看、编辑和确认删除；奶量趋势、喂养与睡眠、生长发育、身体与状态入口保留。
4. Momcozy AI：欢迎页形象循环和三个入口；进入会话后标题收紧，聊天独立滚动，输入区固定在 Dock 上方。文本和任务卡片共用对话时间线，每条 AI 回复有形象和 momcozy ai 署名。
5. 我的：基础照护资料、妈妈资料、宝宝资料、设备与应用记录同步。设备连接与手工日志同步分开。
6. 新用户引导：身份 → 基础资料 → 关注点 → 功能推荐。可暂停、刷新续填；完成更新资料并进入 Today。

三、本轮组件与交互
数据采集：身份、妈妈/宝宝分区、九项关注与推荐入口按语义使用 SVG 图标，保留文字和选中提示。妈妈身份才显示选填阶段；数字为页内纵向滚轮，中央焦点和相邻值，无额外加减按钮。妈妈与宝宝字段同页，多个宝宝按标签切换，生日仍为日期输入。
会话任务：听哭闹、看便便和记一笔以发起顺序插入消息流，状态在同一任务卡片推进。结束的卡片保留；新的任务不统一堆到消息顶部。已有对话迁移保留原任务与消息，旧数据缺少精确穿插位置时不伪造真实时间。
会话记一笔：卡片内完成类型选择、字段填写、校验、保存和回执。草稿及保存请求归属会话任务，不复用 Today/记录入口的未提交草稿；成功后进入共同的妈妈/宝宝日志。切换/恢复对话保留任务草稿，保存中的中断需明确恢复。
全局记一笔：页面内底部弹窗，类型按宝宝和妈妈分组；亲喂为侧别/时长，奶量类为量及开始/可选结束，尿布为情况和红屁屁。字段分组、选项、图标、说明和返回入口遵循现有规范。草稿仅为当前页面会话内状态。
追加服务：完成的 AI 回复和终态任务卡片保留记一笔、听哭闹、看便便三个入口。
历史：新对话回欢迎页，保留旧会话；支持标题/内容搜索、重命名、恢复和确认删除。删除当前会话回欢迎页；其他会话保持。

四、final-audit-13 修复范围
F01：妈妈阶段为空时保留空值；编辑阶段不隐式清空已保存宝宝资料。
F02：引导和宝宝资料共用本机当前日期上限及生日选填规则，记录演示时钟不参与生日上限。
F03：保存前校验全部将保存的宝宝；隐藏的无效生日应定位并阻止提交。
F04：删除保存删除标记并撤销关联待处理操作；旧保存核对/重试不得恢复已删除记录。
F05：关键词和快捷入口生成任务时，进入当前对话时间顺序位置并保持可见、可操作。

五、数据与时间
记录、资料、阅读设置、对话历史及会话卡片草稿使用当前浏览器存储；本机保存与模拟云同步分开。记录演示日期为 2026-10-19 15:00 UTC+08，基础资料生日按用户本机日期校验。
file:// 单文件、http://127.0.0.1:4192 和 http://localhost:4192 不应视为共享数据源。HTTP 数据按源隔离；file:// 存储行为取决于浏览器，不能依赖与 HTTP 共用。存储不可用时原型提示仅保留当前页面；不要将本地演示作为正式数据存储。
当前仅录入多宝宝基础资料，Today 以宝宝 1 显示天数，日志尚未扩展到逐宝宝归属。
