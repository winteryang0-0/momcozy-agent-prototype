01 决策摘要

本轮用户确认 B：iOS 与 Android 共用产品风格，分别适配平台材质与反馈。
情绪连续性：可靠省心 C > 理解陪伴 B > 有条理引导 A。
设计承诺：内容看得清、状态说得准、操作可恢复、运动有目的。
现代化的可观察变化：
1. 主要 UI 由 Montserrat 候选改为系统字体；任务标题、正文、数字和说明形成稳定层级。
2. 从浅色卡片堆叠转为任务分组；常规内容不靠阴影和透明度建立层级。
3. 内容保持稳定实体表面，操作工具层在空间上可辨；iOS 与 Android 分别实现。
4. 品牌莓红集中于主动作与重点；一屏避免多个同等级主动作。
5. 控件默认/按压/选中/焦点/不可用与异步任务状态分别定义。
6. 用明确起终点、作用属性与中断规则代替统一 ease 或持续装饰动画。
以上为本项目设计判断，不是用户验证过的偏好结论。

04 平台适配层

iOS：
采用支持 Liquid Glass 的系统组件，默认 regular，主要位于导航/工具/瞬时控制层。[S01,S02]
新系统材质可用性以具体组件运行时能力判断；本轮没有裁定最低支持的 iOS 版本。
旧系统/能力不足时使用平台标准材质或实体工具层，保留相同状态与任务层级。
长记录、表单正文、分析结果不玻璃化；避免玻璃叠玻璃与自制大面积折射。[S01,S02]
主操作如采用原生玻璃按钮，应使用系统 tint；HTML 实色按钮仅用于确认品牌权重。
系统控件的透明度、形变、触摸响应和动画由系统管理；不把 CSS blur 22px 称为 Apple 标准。
本文不采用 clear 作为常规照护界面的默认变体。

Android：
使用 Material 3 主题角色与标准组件；工具层用 tonal surface，按压用原生反馈。[S03]
共享品牌色角色、信息分组、状态与动作语义；不要求复制苹果光学玻璃或弹簧。
动态配色暂不作为首版默认：保留品牌主动作；若引入，需单独检验语义色与对比度。
返回、底部系统区与支持的预测返回交由原生框架适配，平台 API/版本待实施确认。
HTML 的 ripple 为视觉示例，不等同 Android 系统 ripple 或触觉反馈。

05 两个状态轴与措辞

保存轴：草稿 -> 请求中 -> 成功 / 明确失败 / 结果未知。
同步轴：不适用 / 待同步 / 同步中 / 已同步 / 同步失败。
显示组合由实际能力和响应决定，禁止从时间流逝推断成功。

ID | 状态/文案 | 视觉与可用操作 | 数据规则
review | Not saved yet | 空心圆+中性文本；Save entry / Edit | 尚未保存
saving | Saving entry… | 中性进行图标+状态文字；提交禁用 | 防重复，内容稳定
synced | Saved and synced | 勾+具体成功文本；Edit | 保存与同步分别被确认后
local | Saved on this device / Sync pending | 上行符号+中性说明 | 只有确有持久化时；其他设备可能未更新
syncing | Syncing entry… | 同步图标+文本；保留已保存说明 | 不重新创建记录
syncFailed | Saved here. Sync failed. | 同步符号+错误文本；Retry sync | 不把本地已保存改称保存失败
failed | Couldn’t save | 感叹号+错误文本；Try again / Edit | 仅在明确失败后；保留输入承诺须真实
unknown | Save status unknown | 问号+中性文本；Check status | 超时不等于失败，先核验原请求
checking | Checking save status… | 中性核验状态；提交/编辑暂不可用 | 查询原请求，不发送第二次创建请求
analyzing | Reviewing your recording… | 中性进行图标+文字 | 不伪造百分比和完成时间
indeterminate | We couldn’t draw a conclusion. | 信息图标+中性说明 | 不归咎用户，不使用成功勾或系统错误红

unknown 的核验可能返回成功、明确未保存或仍未知。当前实验室只模拟核验返回成功，不能代表正式恢复流程。
编辑：实验室点击 Edit -> 对话框 -> Apply changes 更新草稿/回到未保存；Cancel/Escape 丢弃本次字段修改，保留打开前记录。
实验室在请求中、同步待完成、同步失败、未知阶段暂禁用 Edit，以避免把未定义冲突策略伪装成确定业务；说明由状态文案承接。
正式版本的离线编辑、可取消请求、幂等键、冲突、重启恢复和核验接口是实施待决，需 PRD/API 闭环。
分析/保存分组独立；分析完成不得自动显示“记录保存成功”。
按钮不可用必须同时让原因可见；不能只淡化控件。

06 控件状态规范

默认：主动作高对比；次动作文字；触控边界清楚。
按压：自定义控件 scale 1→.98；Android 标准组件使用原生 ripple/state layer，不叠加自定义缩放。
选中：保留高对比文字+选中容器/标记，读屏声明 selected/pressed，不仅变色。
键盘焦点：2–3逻辑单位可辨焦点环，偏移2–4；不得被容器裁切；触控不常驻焦点装饰。
不可用：中性色+disabled语义，原因用旁边文字表示；不要依赖 opacity 统一降低整个内容。
处理中：按钮文本变为任务动词进行时；阻止重复提交；请求失败后恢复可执行入口。
错误：图标+准确对象+动作；不晃动整页、不用音效惩罚用户。
成功：简短文本+勾，状态保留于原位置；无需庆祝、积分、长篇安慰或自动发声。
Hover 仅适用于指针输入，不能成为发现操作的唯一手段。

07 动效签名与曲线

以下数值均为项目候选，不是 Apple / Google 官方指定参数。系统组件/系统手势优先遵循平台实现。
名称 | 触发 | 属性/幅度 | 时长 | cubic-bezier | 终点/中断
press | 指针/触摸按下 | scale 1→.98 | 80ms | (.2,0,0,1) | 不超调；取消与抬起进入release
release | 抬起/取消 | scale 当前值→1 | 180ms | (.2,.8,.2,1) | 从当前呈现值连续恢复
enter | 新内容/自定义轻面板出现 | Y 12→0，opacity 0→1 | 280ms | (.16,1,.3,1) | 无回弹；只作用于进入对象
exit | 自定义轻面板关闭 | Y 0→8，opacity 1→0 | 180ms | (.4,0,1,1) | 焦点回到触发控件
state | 实际任务状态改变 | 图标opacity .55→1；文本立即更新 | 160ms | (.2,0,0,1) | 不让关键文字经历低对比淡入

持续活动：如使用进行指示器，原生 indeterminate，不提供虚假百分比；减少动态时替换为静态图标+文字。
手势跟随：拖拽阶段位置由手势1:1驱动；释放使用原生弹簧与当前速度；本版不伪造跨端等价弹簧数字。
系统弹簧与自定义缓动职责分开。若未来使用自定义弹簧，必须另定阻尼/刚度或平台等价参数并在真机核验，不能直接套通用 duration。
中断：转场接收反向操作时从当前呈现位置和速度继续，不跳回初始帧；同一控件不排队播放过时反馈。
请求：第一次有效提交即锁定请求入口；即使按压释放动画未结束，也立即处理真实业务响应。
长任务：状态持续到真实响应或明确错误；动画不设“演完即成功”。
稳定性：不持续呼吸、漂浮、眨眼，不自动声音；AI 角色静止默认。
触感：原生短促选择/完成反馈可作为补充，遵循系统偏好；不依赖触感表达唯一状态，错误不连续震动。
实验室曲线演示可慢放4倍，仅为评审；每次播放明确重启示范，不冒充手势中断验收。
实验室编辑框采用浏览器对话框，未模拟原生大面板进入/退出；曲线台单独演示自定义入场/离场。

08 环境、辅助模式与优先级

优先级：真实状态和文字 > 可读性/系统辅助设置 > 平台行为 > 品牌装饰与透明效果。
减少动态：即时更新状态，取消非必要位移、缩放、旋转与背景运动；必要信息仍保留文本/图标。[S05]
HTML 同时响应 prefers-reduced-motion 与样张开关；系统开启时，样张开关不可强行恢复运动。
降低透明度：操作层改为不透明 surface，关闭 backdrop blur，仍保留边界。
增强对比：不透明优先；亮色辅助文字#403935、边界#625B57；夜间辅助文字#E5D9D5、边界#C4B7B4。
夜间：使用独立暗色角色；深色并不自动等于减少运动；原生随系统且允许产品已有偏好规则。
字号：正式平台支持 Dynamic Type/font scale；大字号不固定卡片高度，按钮可换行，横排允许纵向重排。
读屏：控件有名称、角色和状态；任务结果只播报一次；错误关联相应字段；模态焦点进入并返回。
色觉：灰度也能依靠图标/文案识别状态。
触控：Android 最小48dp。[S06] 本版 iOS 48pt 是本项目采用的宽裕候选值。
性能：原生标准材质优先；减少重叠透明层；低能力路径回退不透明。当前未测帧率、功耗或GPU负担。

09 验收矩阵与未决

本地样板目标：桌面评审 + 390/360 CSS px 窄屏；iOS/Android外观 × 亮暗 × 8个示例状态。
必要交互：保存成功、失败重试、本地待同步、同步失败恢复、结果未知核验、编辑应用/取消、重置清除在途模拟、五曲线播放与慢放、减少动态覆盖。
静态检查：资源本地、JS语法、纯色色对、相对链接、源文件与候选摘要。
实际执行覆盖以 reviews/runtime.json、截图及 challenger.txt 为准，不把验收目标等同于已通过。
尚未验收：iOS真实Liquid Glass、Android原生组件、系统返回/手势弹簧、触感、VoiceOver/TalkBack、所有动态字号、真实低亮度、业务API与跨设备恢复。
待决不阻止风格候选：最低系统版本、技术栈、所有正式页面映射、旧版回退设备范围、品牌动态配色策略、离线/同步具体能力。
正式 UI 实施前：对照批准的页面框架，把各状态/控件逐项映射至真实页面；不得将本实验室的布局当作新首页或新导航。
