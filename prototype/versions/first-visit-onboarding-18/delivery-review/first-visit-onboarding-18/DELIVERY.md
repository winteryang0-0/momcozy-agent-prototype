# 新用户首次资料录入候选交付（R18）

日期：2026-10-20。状态：**可交互候选，未冻结**。当前版本沿用 CS-0.5「莓色留白」及既有首页、记录和会话架构；本轮把已有的四步资料录入接入本机新用户首次打开流程。需求与假设见 `sources/first-visit-onboarding-18-requirements.json`，上一完整版本见 `../versions/smart-reminders-entry-sound-17/`。

## 本轮路径

1. 本机无既有原型资料、会话和引导状态时，打开首页或记录深链，进入照护身份步骤。身份必选。
2. 依次进入基础资料、关注点、功能推荐；阶段、数字资料、宝宝生日和关注点均可暂不填写。数字滚轮初始显示「暂不填」，实际未选时保存空值。
3. 「上一步」可返回；进行中刷新或改写地址，继续留在录入页；「稍后设置」进入首页并保留草稿，可从记录页右上个人菜单续填。
4. 完成后保存实际录入的资料并回到首页；再次打开不重复引导。已有本机资料或会话的用户沿用原首页，不清空现有记录。
