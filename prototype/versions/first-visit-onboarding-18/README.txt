Momcozy · 新用户首次资料录入候选 18
日期：2026-10-20；状态：可交互候选，尚未冻结。

打开方式
1. 双击 Momcozy-final.html：样式、脚本和形象图片均已内嵌。当前版本已在 Chrome 155 的 file:// 环境运行关键路径。
2. 打开 index.html：需保留同目录 assets/。也可在本目录执行 node preview.cjs 进行本机预览。
3. 本机全新用户首次打开会进入 #/onboarding 四步录入，完成或点击「稍后设置」后进入 #/home。录入进行中刷新或输入其他页面地址，仍返回当前步骤；稍后设置后可从「记录 → 右上个人菜单 → 基础照护资料」续填。已有本机资料或会话的用户仍进入原首页。旧 #/assistant 链接自动转到 #/home。

当前结构与操作
- 首页左上角直接进入当日记录；右上角切换声音偏好。开启状态写入当前浏览器，结果页主动点击播报演示时可调用浏览器系统语音；关闭状态停止进行中的播报。
- Today 为一张由本机记录和资料生成的演示提醒卡，可点击箭头或圆点、左右滑动，也可聚焦卡片后按左右方向键切换；「查看依据」展示提示依据。进入对话后 Today 缩为一行，点击整条卡片可恢复默认完整大小，再次点击可收起。新建对话后回到默认收缩规则。
- 底部输入框默认一行。欢迎态保留记一笔、听哭闹、看便便入口；会话、历史、专项任务和草稿继续使用原有逻辑。没有三栏底部导航。
- 记录页保留日期、对象、摘要、时间线、筛选和固定底部「新建记录」。右上个人按钮打开「我的与二级功能」面板，可进入资料、设备与同步、历史对话、新对话及设置。我的页返回记录页。
- 首次资料录入依次为照护身份、基础资料、关注点和功能推荐。身份必选；妈妈阶段、数字资料、宝宝生日与关注点可以不填。数字滚轮未选择时显示「暂不填」，不会自动替用户保存示例数字。中途返回、稍后设置和刷新均保留草稿；完成后只保存实际输入的资料，不生成虚构记录。

数据与边界
- 沿用原有浏览器存储键；本地记录、资料、会话与草稿不会因页面改版自动清除。记录演示时间固定为 2026-10-20 15:00（UTC+08:00）；未自动注入示例记录。
- 智能提示、AI 回复、语音转写、相机、附件、设备连接及同步均是本地演示；提示不提供诊断或治疗建议。系统语音能否播放取决于浏览器和设备语音支持。
- 视觉沿用 CS-0.5「莓色留白」。本轮范围和假设见 sources/first-visit-onboarding-18-requirements.json；此前完整版本在 ../versions/smart-reminders-entry-sound-17/。
