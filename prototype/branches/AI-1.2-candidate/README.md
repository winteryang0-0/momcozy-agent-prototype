# AI-1.2 莓色留白候选

日期：2026-10-20。状态：**供用户评审，未冻结**。此目录独立于 AI-1.1 与 `prototype/current`。

## 打开

- [index.html](index.html) 与 `assets/`：可维护的多文件原型。
- [Momcozy-final.html](Momcozy-final.html)：内联 CSS、JavaScript 与动态形象 PNG 的单文件原型。
- 本轮实测使用 `node preview.cjs` 启动本地 HTTP（默认 4195 端口）。如需隔离浏览器本机数据，可设置 `MOMCOZY_PREVIEW_PORT` 后再启动。最终截图使用隔离端口 4198（录入与已填资料）和 4199（零资料 AI）。
- 浏览器安全策略不允许代理导航 `file://`，因此直开未验证；请以本地 HTTP 检查交互。

## 本轮设计差异

| 区域 | AI-1.2 候选 |
| --- | --- |
| 首次进入 | 没有本版资料、记录或会话时进入四步录入：身份 → 基础资料 → 关注点 → 核对。只有角色必选，可稍后设置、刷新恢复草稿。 |
| AI 主页 | 每个本地日历日首次进入展示紧凑的动态形象卡与当日行动建议；当天再次进入或刷新时只保留建议。建议显示资料或本机记录依据，资料为空时提示先补充。 |
| 持续对话 | 沿用一条对话、顶部个人入口与快速静音；默认输入框保持单行高度，AI 页 Dock 仅含 Today／记录。 |
| Today／记录 | 均移除悬浮 Dock，左上角独立返回按钮直达 AI；Today 只展示建议与当日概况。 |
| 风格 | 沿用 AI-1.1 的 CS-0.5「莓色留白」候选 CSS，新增紧凑开场卡和次级页玻璃质感返回按钮。 |

原型仅使用本机浏览器存储，AI-1.2 的键与 AI-1.1、`current` 分离。演示设置中的“重置本版演示数据”只针对 AI-1.2；如本机已有重要试用数据，请勿重置。行动建议、对话回复、记录与设备反馈均为本地模拟，不连接真实模型、医疗服务、麦克风、设备或云端。
