# Momcozy AI 优先架构 · 候选分支

状态：**交互候选，尚待用户确认，不替换 `prototype/current/`**。视觉沿用 CS-0.3 花瓣玻璃；业务原型在独立目录中演示新的导航与内容层级。

## 打开

- 直接打开 `Momcozy-final.html` 查看自包含候选。`file://` 直开运行未在本轮浏览器策略下验证。
- 或在本目录执行 `node preview.cjs`，打开 `http://127.0.0.1:4193/#/assistant`。本轮实测使用此入口。
- `index.html` + `assets/` 是可维护的分文件版；`node build-standalone.cjs` 可重新生成单文件版。

## 本轮架构候选

| 页面 | 职责与主要控件 | 导航 |
|---|---|---|
| Momcozy AI，默认入口 | 顶部左侧个人入口、右侧快速静音；今日建议卡；一条持续的会话、任务卡与输入框 | Dock 悬浮在输入框上方，切换 Today / AI / 记录 |
| Today，次级页 | 当天行动建议与当日概况的只读展示；缺记录时明确“未记录不代表未发生” | Dock 返回 AI 或进入记录 |
| 记录，次级页 | 延用宝宝/妈妈记录、详情与新增入口 | Dock 返回 AI 或 Today |
| 我的 | 照护资料、设备与同步演示 | 从 AI 顶部个人入口进入，顶部返回 AI |
| 基础资料引导 | 由“我的”主动进入并可暂停、完成 | 返回来源页；首次打开不强制挡住 AI 入口 |

**持续对话**：只有一个活跃会话；刷新和跨页面继续，界面没有新建或历史对话入口。旧交付版若在同一浏览器源下有资料、记录或对话，候选首次载入只复制一份数据到 `momcozy-ai-first-1.0` 命名空间。原版数据不会被候选写回。旧版多条历史仅取当前活跃条；候选重置后不再重新导入。

**行动建议**：基于本地当天记录和用户主动填写的关注点，按可解释规则生成两张模拟卡。每张卡显示依据与下一步；不设定医学阈值，不把缺少记录判为照护缺失。Today 的卡片只读；AI 页卡片可进入同一条对话的任务或预填问题。记录改变后重算，日期以浏览器本机日历为准。真实 AI、通知和设备联动未接入。

**静音**：顶部按钮保存开关状态。打开声音仅允许主动触发原有的播报口型演示；原型不播放声音。静音时停止正在演示的播报口型，不影响文字和记录。

## 关键任务检查

1. 默认进入 AI → 可见今日建议 → 点“记一笔”建议 → 在同一会话中打开记录卡 → 刷新后任务仍在。
2. AI Dock → Today：只有建议和概况，无快捷功能入口 → Dock 进入记录 → Dock 返回 AI。
3. AI 顶部进入“我的” → 从顶部返回 AI；静音切换有明确标签、状态和提示。
4. 输入框、Dock 和对话滚动区各自可达；短屏与深色需独立视觉复核。

当前浏览器实测覆盖了 1–3 的导航、建议进入任务、刷新恢复与静音切换；记录保存完整路径、跨日刷新、短屏/深色、移动软键盘及 `file://` 直开仍需补测。此版本未冻结。
