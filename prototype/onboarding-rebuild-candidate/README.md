# Momcozy Onboarding · 独立重构候选

双击 index.html 即可在浏览器中体验。所有资源均在本目录内，无需安装依赖或启动服务器。目标视口为 390×844、360×640 与桌面 1440×900；系统深色模式会切换夜间配色。本目录是待审候选，不会改写旧原型。

## 使用

1. 首次打开进入「照护身份」。
2. 按顺序体验「基础资料 → 关注点 → 功能推荐」，最后完成本地保存。
3. 点击「稍后设置」可暂停；点击「继续填写」恢复；刷新页面保留进度。
4. 完成页可点击「修改资料」从第一步查看、编辑，原值仍保留。

数据只写入当前浏览器的 momcozy-onboarding-rebuild-v1 键，不读取旧原型的存储键。若需从全新状态演示，可在浏览器开发者工具的本地存储中**仅删除此键**后刷新。保存失败会显示错误并阻止完成状态。

## 文件

- index.html：四步及暂停、完成状态的静态页面结构
- assets/styles.css：莓色留白候选样式与夜间、窄屏规则
- assets/app.js、assets/icons.js：流程、校验、本地草稿、语义图标
- source/requirements.json：本轮来源与需求摘录
- design.json、STYLE_SPEC.md：候选框架、控件映射与设计说明
- reviews/：真实浏览器截图、运行记录与自审记录
- qa-browser.cjs：本地 Chrome / Playwright 的 `file://` 测试脚本
- check-candidate.py：候选设计账本结构检查。`D-01` 待用户确认，不视为失败修复对象

此项目是**待审候选**，独立于 prototype/current。它不会自动把完成的数据写回旧原型。功能推荐仅展示工具名称和排序，没有接入识别服务。浏览器无法保存时，可继续查看内容，但不能完成或暂停为“已保存”；请保持页面打开并重试。浏览器无法读取旧草稿时，新输入不会覆盖旧存储。
