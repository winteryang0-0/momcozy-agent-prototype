截至 2026-10-20，后续需求管理以本目录为入口。

## 阅读顺序

1. [第14轮需求增量.md](第14轮需求增量.md)：最近一次明确的原型需求修订，含继承规则与范围边界。
2. [需求拆解-历史会话汇编.md](需求拆解-历史会话汇编.md)：历史「重构需求拆解与原型交互」会话中的五轮需求理解与页面交互拆解。
3. `sources/`：三份来源 JSON 的逐字节副本；`evidence/`：历史会话所用的 21 张截图副本。
4. `manifest.json`：源文件、截图和文档的 SHA-256 核对信息。

## 版本与使用边界

- 历史会话的拆解是依据当时截图形成的理解稿。截图未展示的业务行为仍属待定义项。
- 第14轮记录是「已授权实现的候选」，并未冻结为 PRD 或正式设计基线。
- 会话内「记录进入独立表单」描述的是当时截图；第14轮修订要求会话内「记一笔」改为独立任务卡，Today / 记录入口仍按其自身流程。迭代时以明确的后续用户指令为准。
- 需求讨论、确认和修订从本目录延续；不要把原型模拟能力写成真实 AI、采集或同步能力。
