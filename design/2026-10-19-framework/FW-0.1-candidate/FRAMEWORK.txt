信息架构
身份选择 → 阶段 → 基本信息 → 本次分娩 → 当前关注 → 服务推荐 → 主对话
主对话 → 底部记录类型面板 → 亲喂 / 配方奶 / 瓶喂母乳 / 换尿布 / 吸奶
记录保存 → 同会话记录摘要 → 查看/修改 → 保存同一记录
主对话 → 听哭闹卡片 / 看便便卡片 → 采集 → 确认素材 → 处理中 → 结果/无法判断/失败
取消保留当前卡片；再启动同类任务时历史摘要保留于对话。
菜单、声音、图片、语音、更多：恢复已展示入口。无来源内容用边界说明；不新增完整菜单体系。

必要补充（候选，非原始既定需求）
- 记录草稿按类型保留；编辑保留记录ID；保存防重入；成功返回原会话。
- 奶量空白输入，不采用截图50ml为正式默认；加减10ml仅演示。
- 亲喂手动时长；双侧为本次总时长演示，未定义实时计时。
- 时间默认浏览器当前本地时间；显示保存时区；禁止未来时间及结束早于开始；不实现云端时区规则。
- 表单必填和数值范围仅供框架验证，业务冻结前须确认。
- 任务素材确认、结果结构、重试取消为闭环补齐；无医学推断。
- 单一当前会话，每种专项任务一个当前卡片；完成后可再次发起并保留历史状态摘要；不宣称多任务后台能力。

未提供/范围外
备孕和孕期后续分支、完整侧菜单、多宝宝独立档案、账号/家庭共享、商城/设备、通知/后台同步、真实AI/录音/拍照。
语音转文字和声音开关仅是可检查的候选表达。

后续填充规则
先确认页面职责、跳转、任务承载和必要补充，再冻结候选摘要；在同一框架中填充UI与业务内容。新增页面或改变记录归属另行记录差异。

文件
bundle/index.html 可点击原型；design.json 需求-页面-控件-状态映射与验收计划；candidate-summary.json 四项摘要；reviews 实际验证和独立挑战记录。
