FW-0.4 候选包 · 本地可替换资产接入约定
更新：2026-10-19

1. 范围与来源
本包提供 1 个陪伴角色 SVG 占位、13 个 SVG 图标及 asset-map.js。
全部图形为本原型以代码自绘的中性占位，未调用 imagegen，不是 Momcozy 官方品牌素材、正式角色或正式视觉授权资产。后续正式素材应由获授权来源提供。
所有文件均本地引用，无远程字体、图片、脚本、追踪或 SVG 外链资源。

2. 角色职责与边界
用户已选角色 A：陪伴展示 + 状态反馈。角色置于固定 72×72 CSS 像素容器中，保持完整可见，object-fit: contain，不裁切、不拉伸、不改变周围布局。
角色是装饰性展示，不附加点击、键盘焦点、语音唤起、录音或相机权限行为。语音输入仍由独立的“语音输入”文本按钮承担，使用 microphone 图标。
角色不独自承担状态含义；相邻文字必须解释“准备好”“正在处理”或“请补充 / 请重试”等当前含义。状态不能仅依靠表情、颜色或动画区分。

3. 文件与状态映射
在 bundle/index.html 中，先加载 assets/asset-map.js，再加载依赖它的 assets/app.js。
window.MOMCOZY_ASSETS 是唯一资产路径表；路径均相对 bundle/index.html，而非 asset-map.js 所在目录。
companion.idle      → assets/companion/placeholder.svg：初始、空闲、完成后可继续交流。
companion.busy      → assets/companion/placeholder.svg：发送、生成、分析等有真实进行中状态时。
companion.attention → assets/companion/placeholder.svg：错误、无法判断、缺少素材或需要用户补充。
候选版三种状态刻意共用静态占位，状态差异由既有文字反馈表达。任务状态来源必须复用实际任务 / 发送状态，不单独模拟计时制造进度。

4. 角色替换规格
首选透明 SVG / PNG / WebP。推荐方形 1:1 画布；SVG viewBox="0 0 72 72"，位图至少 144×144（2×），建议 216×216（3×）。
以 72×72 为基准，主体及效果须落在 x=8…64、y=8…64 的安全区；透明留白约 8px，避免阴影或肢体触及画布外沿。光学中心宜接近 (36,36)。
当前占位外形在上述区域内，透明背景，不嵌入标题、按钮、提示文字或品牌标识。
可直接用新文件覆盖 placeholder.svg；若更换格式或为三种状态提供不同文件，仅修改 asset-map.js 对应路径。替换后仍按 contain 显示。
需要轻动效时，优先保留同构图静态封面。不得使用会自动播放且无法提供静态替代的动图；原型默认静态。

5. 图标职责与规格
icons.record：记录一次日常；图形为记录板。
icons.cry：听哭闹；图形为声音波形。
icons.poop：看便便；图形为尿布，需由“看便便”文本明确任务。
icons.menu：打开导航菜单。
icons.sound：声音设置；“声音开 / 关”由文本或可读状态明确，图标本身不代表当前开关状态。
icons.camera：拍照或相机素材入口。
icons.microphone：独立语音输入入口。
icons.upload：上传已有素材。
icons.chevron：进入下一级。
icons.services：服务集合 / 更多服务。
icons.close：关闭浮层。
icons.collapse：收起内容，向上折线。
icons.expand：展开内容，向下折线。
所有图标为 assets/icons/<key>.svg，24×24 画布、viewBox="0 0 24 24"、2px 线宽、圆端和圆角、中性单色 #53635A。
常规图形范围 x/y=3…21；camera 的横向边缘和 microphone 的底部延伸到 2…22（含线宽仍在画布内）。替换图标须保持相同光学尺寸和 24×24 比例，避免按钮布局跳动。
SVG 内不使用 emoji、文字字形、外部 symbol、字体或脚本。外部 <img> 不继承 CSS currentColor；需换色时更新文件颜色，或采用经审查的内联 SVG 接入。

6. 加载、失败、缺失与减少动效
加载前：角色框固定 72×72；图标框固定 24×24；文字及控件立即可用，避免资源延迟造成布局位移。
加载成功：显示资产；角色和图标均为装饰，img 使用 alt=""、aria-hidden="true"，不可聚焦。按钮保留可见的中文文本标签；名称、开关状态和任务进度由 DOM 文本提供。
路径缺失 / key 缺失 / asset-map.js 未加载：功能和文字保持可用。角色显示原容器的中性静态底形或隐藏装饰但保留占位；图标隐藏图形并保留原尺寸或有意收回空隙，按钮文本不得消失。
请求失败 / 非法文件 / 图片解码失败：绑定一次性 onerror，清理失败 src 并隐藏破图图形，保留角色框或按钮文本；不得循环重试同一失败路径，不向产品使用者展示开发配置入口。
动态替换 src 时应重置成功 / 失败外观，防止上一次失败遮蔽后续有效素材。旧资源加载结果不应覆盖较新的状态选择。
prefers-reduced-motion: reduce：角色、阴影及其附属元素关闭 transform、transition、animation，展示同一静态姿态；“正在处理”仍用可读文字表达。SVG 占位本身完全静态。
动效不控制业务完成、不改变焦点、不播放声音；动效关闭不影响交互和任务反馈。

7. 接入示例（交付给实现者，不作为产品界面）
const manifest = window.MOMCOZY_ASSETS || {};
const statePath = manifest.companion?.[state] || manifest.companion?.idle;
仅在 statePath 为非空字符串时给角色 img 设置 src；否则进入第 6 节缺失降级。
图标按 manifest.icons?.[key] 取值；不以图标是否存在决定按钮是否可操作。
主实现负责 DOM 布局、映射到既有状态、img 的 load / error 处理及 CSS 减少动效规则。本资产包不修改 app.js、styles.css 或 index.html。

8. 替换后的验证
核对 asset-map.js 的 3 个角色 key、13 个图标 key 与本地文件路径；检查在 bundle/index.html 打开时可加载。
在 72×72 / 24×24 实际显示尺寸及手机窄视口查看：无裁切、无拉伸、无布局位移，文本标签完整。
逐一覆盖 idle / busy / attention；确认角色不可点击，焦点不会落入角色，语音入口仍独立。
临时使用不存在路径、缺失 key、无效图片及不加载 manifest：确认无破图残留，按钮和文字仍可操作，任务状态文字仍可理解。
开启系统减少动效偏好：确认所有角色装饰动效停止，加载 / 进行中 / 失败反馈可读。
检查替换素材来源与授权记录；本文件的“中性自绘占位”来源说明仅适用于当前随包素材，不覆盖后续替换资产。
