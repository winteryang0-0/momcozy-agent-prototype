# 02 折叠助手 · 动画候选 V0.3

入口：`index.html`。本页用于评审动作节奏与形象一致性，尚未冻结为角色资产。

## 素材来源

- `assets/folded-hero-original-pixels.png` 逐字节复制自 V0.2 裁切图，来源是 `design/2026-10-19-ai-characters/folded-assistant-v0.1.png` 的主视角。
- `assets/folded-front-original-pixels.png` 裁自同一概念板的正面视角。可见 RGB 保留原图，仅在外轮廓添加透明遮罩；提取步骤在 `extract_front.py`。
- `assets/folded-head-shell.png` 仅供成形中段翻起头部时使用；两处眼睛由原图周围象牙白像素补全，生成步骤在 `build_head_shell.py`。接近成形终点时恢复原眼睛，终帧直接绘制未改的主视角原 PNG。
- 原概念板只提供静态主视角、正面和侧面，没有可编辑的三维网格、材质贴图或骨骼。背面视角若有展示，仍是推断参考。

## 动作与边界

| 动作 | 时长 | 实现与边界 |
| --- | ---: | --- |
| 丝带成形 | 2.4 秒 | 将原图下部折面压成窄带，先展开身体与短翼，再让头部折面翻起；终帧直接绘制主视角原 PNG。中间拓扑和透视为二维半推断。 |
| 轻跳 | 1.3 秒 | 整张主视角原图短暂上移和轻压，五官与折线保持原像素关系。 |
| 折翼内收 | 1.7 秒 | 使用原概念板正面视角，将两侧折翼裁出后向胸前靠拢两次；翼根背后和身体补面为推断。此片段是拍手方向预研，不能视为可信的三维拍手。 |
| 轻摇 | 1.8 秒 | 整张主视角原图以底部为轴轻微摆动。 |

播放器支持切换动作、播放、暂停、逐帧拖动、循环、慢放和减少动态。成形循环采用往返播放，避免终帧突然跳回平带；系统启用减少动态时默认展示动作终帧，仍可手动逐帧查看。

## 核查

`reviews/render-keyframes.cjs` 直接执行当前 `assets/app.js` 并离线导出关键帧。`reviews/frames/` 中的图片用于检查头部、折翼、轮廓、完整入镜及终帧。该检查不能代替真实浏览器中的按钮、滑杆、视口与播放流畅度复核。

当前最大的未决点是折翼内收的翼根和遮挡；若要完成同模型、同材质且可从各视角成立的真实拍手，需要可编辑的三维模型或经过确认的多视角重建资产。中间帧不能被当作已验证的三维形变。
