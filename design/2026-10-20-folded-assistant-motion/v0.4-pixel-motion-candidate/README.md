# 02 折叠助手 · 动画候选 V0.4

入口：`index.html`。也可运行 `node preview.cjs`，在浏览器打开 `http://127.0.0.1:4196/`。本页只评审轻跳与轻摇的动作节奏和原形象一致性，尚未冻结为角色资产。

## 素材来源

- `assets/source-concept-board.png` 是原始概念板在本候选包中的副本，供页面右侧对照。
- `assets/folded-hero-original-pixels.png` 复制自 V0.2 的主视角裁切图。两段动作都直接使用这张 PNG 的完整轮廓、折面和五官，没有重绘局部结构。
- 原概念板是静态视角，本页没有可编辑的三维网格、材质贴图或骨骼。

## 动作与边界

| 动作 | 时长 | 实现 |
| --- | ---: | --- |
| 轻跳 | 1.3 秒 | 整张主视角 PNG 短暂上移并轻微压缩；影子随高度变化。 |
| 轻摇 | 1.8 秒 | 整张主视角 PNG 以底部为轴轻微转动。 |

播放器支持动作切换、播放、暂停、逐帧拖动、循环、慢放和减少动态。系统启用减少动态时默认展示动作终帧，仍可手动逐帧查看。这两段属于原图的二维整体动效，不能当作经过验证的三维绑定动画。

## 核查

`reviews/render-keyframes.cjs` 直接执行当前 `assets/app.js` 并离线导出轻跳和轻摇的关键帧，同时检查播放器的逐帧、减少动态、循环、长时间间隔及图片迟到时的选片状态。帧图可检查角色是否完整入镜；真实浏览器中的按钮、视口和播放表现仍需另行复核。
