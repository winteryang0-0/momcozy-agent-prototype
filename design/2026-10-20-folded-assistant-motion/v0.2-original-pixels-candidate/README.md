# 02 折叠助手 · 原图像素动效验证 V0.2

**状态：候选，待用户确认。**打开 `index.html` 查看。页面使用本地文件，无在线依赖。

## 与 V0.1 的区别

V0.1 由 SVG 重新画了角色，模型比例和材质光影与原图不同，已停用。本版的角色主视角由 `../../2026-10-19-ai-characters/folded-assistant-v0.1.png` 抠图而来，角色内部 RGB 像素未经重新绘制或调色。预览中的运动仅对整张角色图像做平移和旋转，保留同一主视角的原图外观。

## 能验证的动作

- **轻跳**：原图整体最多上移约 14 CSS px，一次落稳。
- **轻摇**：原图整体在约 ±2.4° 范围内摆动一次。
- **原图静止**：核对角色原貌。

默认单次播放。可暂停、逐帧查看、主动开启循环。操作系统开启减少动态时仅显示静态原图。

## 素材边界

角色对比页的 HTML 将原 PNG 以内嵌图片呈现，没有独立的几何、材质、分层或骨骼数据。当前项目也没有找到可编辑的 02 三维模型。整图轻跳与轻摇保留相同视角和原图表面；**拍手**和**丝带连续扭曲成形**需要不同角度的表面、遮挡与厚度信息，仅凭 PNG 无法做到模型与材质严格一致。本页不把静态概念板误称为 3D 模型。

`extract_hero.py` 可从原始 PNG 重新生成 `assets/folded-hero-original-pixels.png`。提取只添加外轮廓透明通道，非透明内部像素直接复制原图。附原始 PNG 供并排核对。
