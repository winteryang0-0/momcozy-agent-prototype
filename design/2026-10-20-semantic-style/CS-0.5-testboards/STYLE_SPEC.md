# CS-0.5 液态玻璃四风格板 · 任务颜色连续性候选

日期：2026-10-20。状态：待用户测试，未冻结。范围：沿用花瓣玻璃、日光轨道、雨后花园、莓色留白四个方向，细化任务入口、最近记录、时间线、喂养汇总和图标样张的颜色对应；Today、Journal、Momcozy AI 的状态语义保持可比。页面中的记录、同步与 AI 反馈均为模拟。

## 问题界定

- 隐含假设：用户会把同一任务在入口与记录中的颜色视为同一语义线索；四板可用各自色盘表达相同类别，而无需四板使用同一个绝对色值。此处的深莓色仍是项目候选色值，不是已确认的 Momcozy 官方品牌 token。
- 显著缺失：正式品牌主色及使用规范、目标平台与系统版本、主要市场语言、目标设备，以及任务类别是否包含更多正式记录类型。这些会改变正式 token、颜色对比和类别扩展方式。
- 常见错误：只给入口卡分色，却让记录时间线套用一种默认色；另一个错误是把“已保存”的绿色当作任务类别色。本轮给每个任务建立独立 token，并让结果反馈保持独立。

## 可比性与方向差异

四板使用同一份 `assets/board.js`：相同 Today / Journal / Momcozy AI 文案、记录数值、状态集合和测试控件。喂养、哭闹、尿布、睡眠保持相同类别键 `data-task`；各板通过 token 改变色相，类别不会随页面切换而换色。入口卡的概念文案不同，实际手机样张保持一致。

| 方向 | 视觉焦点 | 玻璃与色彩 | 更适合验证 | 主要风险 |
|---|---|---|---|---|
| 01 花瓣玻璃 Bloom Glass | 温暖的最近一次喂养与下一步 | 玫瑰、杏桃、薄荷环境光；香槟玻璃导航 | 照护温度与主任务识别 | 色彩过密、卡片显得甜腻 |
| 02 日光轨道 Daily Orbit | 时间、事件和记录顺序 | 晨光金、珊瑚、嫩绿；偏暖的日期与导航玻璃 | 快速扫描记录 | 时间线被误读为照护完成率 |
| 03 雨后花园 After Rain | 舒展的情绪与照护节奏 | 青绿、湖蓝、嫩芽色、微暖杏色；水滴般的圆润玻璃与清透环境光 | 轻快、清新、愿意继续使用的感受 | 绿色被误读为健康良好，或与“已保存”状态混淆 |
| 04 莓色留白 Berry Poise | 主题色建立稳定焦点 | 深莓主卡与导航强调；柔粉、鼠尾草和浅杏只在任务模块小面积出现；玻璃高光与阴影更收敛 | 品牌感、信息层级和模块辨识度能否共存 | 过于端正或缺少生命力；品牌主色假设可能不符正式规范 |

## 跨组件任务颜色映射

每格依次为浅背景 / 图标与关键文字色。浅背景用于任务入口、最近记录图标、时间线图标和图标样张；同类别使用同一 `--task-*-bg`、`--task-*-ink`。喂养汇总以喂养浅背景渐变到页面实体色；主卡保留各板的深主题背景，同时放置同色系的喂养标记。

## 组件与状态语法

1. **玻璃层**：只作为底部导航、图标操作、日期/轻操作样式和样张外的浮层。由半透明底、边缘高光、模糊、景深阴影及环境色共同表现；不把正文、时间和状态文字置于复杂背景上。HTML `backdrop-filter` 仅模拟视觉，不等同原生 Liquid Glass。
2. **内容焦点**：主卡只强调一个近期事实，数量始终附单位和时间；“3 feeds”只表示已记录的喂养次数。Journal 汇总标题改为 “TODAY’S FEEDS”，避免把喂养数量误读为全部记录。时间线按事件顺序展示，AI 的建议同时交代依据与不确定性。
3. **任务颜色与图标**：24 单位线性 SVG，常规笔画约 1.8；奶瓶、尿布、声波、睡眠、吸奶、日历和 AI 各指向具体对象或任务。喂养、哭闹、尿布、睡眠按上表取色，且始终有对象图标与文字。功能入口、已记录事实和状态结果分别由 `data-task`、记录文案和独立状态类表达；颜色不单独承担语义。
4. **反馈**：保存中、已保存、仅本地保存、失败、结果待核验、AI 分析中、无法判断分别使用不同标题、解释和建议下一步。仅本地保存不暗示云同步成功；结果待核验不暗示可以安全重试；AI 无法判断不等于检测到疾病。手机内的下一步是**状态文案样张**，不触发真实保存或 AI 分析。
5. **可访问性候选**：评审控件具有焦点外环；选择同时用填充与文字标识；支持手动减少透明度/动效和系统 `prefers-reduced-*`。按静态色值计算，任务浅背景与图标色的对比比值为 5.06:1–7.05:1；这不覆盖玻璃叠层、不同亮度或真机渲染。仍需字号放大、图标识别与设备测试，不能声称已符合 WCAG 或原生平台规范。

## 测试步骤与记录表

建议以同样顺序分别打开四板，先不给受试者解释方向名称。每板完成：

1. 看 Today 五秒，说出第一眼看到的事实与下一步；记录是否能说出“最近一次喂养”和时间/单位。
2. 找到 Journal，说出“3 feeds”的含义；记录是否误解为所有喂养或任务完成率。
   核对喂养与尿布在入口、最近记录和时间线的底色及图标色是否自然对应；睡眠在时间线与图标样张是否对应。
3. 找到 Momcozy AI，说出建议的证据、确定性与可做的下一步。
4. 切换“已保存、仅本地保存、保存失败、结果待核验”和 AI“无法判断”；用自己的话解释各状态与下一步。
5. 切换减少透明度与动效；在常用设备上记录亮度、观看距离、是否刺眼及文字是否易读。问第四板能否区分任务，哪些颜色显得多余或不足。

| 指标 | 记录方式 |
|---|---|
| 任务识别 | 正确 / 部分 / 错误；记录原话 |
| 状态理解 | 分别记录已保存、本地、失败、待核验、无法判断的解释 |
| 图标识别 | 先遮住文字猜任务，再显示标签；记下易混淆项 |
| 视觉舒适 | 1–5 分，说明具体发亮或难读区域及使用环境 |
| 偏好与理由 | 四板排序；分别说出一个喜欢与一个妨碍使用的点 |

## 挑战视角（作者自审，非独立评审）

| ID | 质疑 | 当前处理与未决 |

| C06 | 配色克制后任务模块是否仍能迅速区分？ | 奶瓶、声波、尿布继续配文字与对象图标；测试识别率与首次目光落点 |

| C08 | 哭闹与睡眠是否为了展示配色而被虚构成新记录/入口？ | 沿用现有内容：哭闹只展示辅助入口，睡眠只展示记录；色盘和图标样张说明扩展规则，不宣称已有对应功能 |
| C04 | 线性图标是否仍太相近？ | 对象轮廓配合文字；需用遮字识别测试找出混淆项 |
| C05 | 伪手机会不会被当成完整交互原型？ | 只有外部页面切换、底栏导航与状态选择可操作；其余手机内容是样张，不代表保存、同步或 AI 服务 |
