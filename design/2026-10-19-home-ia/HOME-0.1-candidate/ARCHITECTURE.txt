Momcozy 首页信息架构候选 HOME-0.1
日期：2026-10-19 | 状态：候选，未冻结 | 作者：/root

1. 决策摘要
用户选择 B+C：掌握当下为主、快速办事为辅，并倾向传统 Dock 框架。
建议四项底部导航：首页 / 记录 / AI 助手 / 我的。所有项目均为页面目的地，不在导航中央混入“新增”动作。
本轮采用已完成基础资料的新生儿照护场景；多阶段自适应首页尚需单独定义。
本轮未使用参考截图推导布局。功能事实来自已有文字需求拆解，原框架仅用于追踪功能和辨认变更。

2. 首页职责与区域顺序
H01 顶部情境：今天、宝宝姓名/年龄、妈妈所处阶段；点击资料入口进入“我的”。年龄只用于上下文，不独占大卡片。
H02 条件反馈：只在存在可处理的同步问题时出现；无异常不占位。离线不等同于设备未连接；两者在详情分别表达。
H03 今日概况：宝宝喂养次数及最近一次；妈妈今日吸奶量及次数。来源是已记录事件，不把缺数据解释为零摄入，不生成医学评价。
H04 快捷操作：记一笔 / 听哭闹 / 看便便。记一笔展开五种类型，保留业务身份。无频率数据，暂不主张固定把某一种喂养方式放到首位。
H05 进行中的任务：有任务时出现恢复入口；无任务不占位。
H06 最近记录：按发生时间倒序展示三条，可回看记录详情；全部历史在“记录”页。
H07 AI 帮助入口：引导进入连续对话。首页不自动展示大面积聊天记录或自动推断建议。
底部 Dock 始终固定于四个根页面；填表用模态界面，期间不能切换主导航，退出保留本次打开期间草稿。
390x844 为主验收视口，360x800 为窄屏；桌面显示评审说明和手机线框。首屏优先覆盖情境、概况、三个快捷操作，最近记录允许向下延伸。

3. 四个导航目的地
首页：跨妈妈与宝宝的当日摘要、发起动作、恢复未完成任务；不承载完整历史。
记录：宝宝 / 妈妈两个分组；宝宝含喂养与睡眠、生长发育；妈妈含奶量趋势、身体与状态。记录是回顾目的地，“记一笔”是新增动作。
AI 助手：连续对话、听哭闹和看便便的采集/分析任务；原有文字、声音、语音、拍照、上传能力归属此页，不因首页重构被删去。
我的：妈妈资料、宝宝资料、设备入口。原“我的”中的妈妈健康记录移至“记录 → 妈妈”，避免资料管理与健康数据混淆。
设备：位于我的下级，保留设备信息和同步记录；首页异常提示可直接进入。当前清单未证明需要高频控制设备，故暂不占用独立 Tab。若后续加入吸奶器实时控制，应重新评估第五 Tab。

4. 需求映射（原编号保留，新增组织规则另列）
C01 侧菜单 → 四项 Dock；抽屉形式取消，导航职能保留。
C01.1 妈妈概览 → 首页妈妈摘要 / 记录中的妈妈分组；妈妈资料在“我的”。
C01.1.1 奶量趋势、C01.1.2 身体与状态 → 记录 > 妈妈；目标详情规格待补。
C01.2 宝宝概览 → 首页宝宝摘要 / 记录中的宝宝分组；宝宝资料在“我的”。
C01.2.1 喂养与睡眠、C01.2.2 生长发育 → 记录 > 宝宝；睡眠、身长、体重录入来源待补。
C01.3 设备、C01.3.1 设备信息、C01.3.2 同步记录 → 我的 > 设备；未增加实际绑定、云同步功能。
CHAT-AGE / C04 年龄背景 → 首页情境与 AI 助手上下文；对象身份保持一致。
CHAT-TODAY 今日概览 → 首页摘要。取消与聊天消息混排的强制关系。
C09 / C09.1–C09.5 → 记一笔面板 → 亲喂 / 配方奶 / 瓶喂母乳 / 换尿布 / 吸奶表单 → 返回发起页。
C10 / C11 → 首页快捷入口或 AI 页入口 → AI 助手内对应任务；同类任务重复点击定位当前任务。
CHAT-CONTINUOUS → AI 助手内保留连续会话，首页不承担聊天主容器。此为明确的框架变更候选。
C03 声音、C05 AI 形象、C12 文字、C13 拍照、C14 语音、C15 上传 → AI 助手，首页不展开这些控件；本线框只实现文字流程示意。
ONB-01–ONB-06 → 首次资料引导独立于四个根页面，本轮不重构。
新增候选组织规则：H01–H07、四个根页面、返回发起页、同源数据更新、按对象归档、条件异常/任务入口。

5. 核心任务路径
F01 掌握当下：首页 → 读宝宝/妈妈摘要 → 查看记录 → 对应对象历史 → 回看一条 → 返回。
F02 快速记录：首页/记录/AI → 记一笔 → 选类型 → 表单 → 保存 → 返回发起页；首页摘要与记录列表来自同一事件集合。
F03 草稿恢复：表单输入 → 关闭或 Esc → 再选同类型 → 恢复草稿。保存清除该类型草稿。当前演示仅页内保留，刷新重置。
F04 专项任务：首页听哭闹/看便便 → AI 中采集 → 确认素材 → 模拟分析 → 无法判断 → 重试/继续聊。取消后状态可见，导航切换保留任务。
F05 问题恢复：首页离线提示 → 应用记录同步状态及待同步清单 → 返回原页面；与设备同步分开。加载失败可重新加载，快速记录仍可用。

6. 关键状态与产品规则
正常：展示已记录次数/奶量及最近事件，保持妈妈吸出量与宝宝摄入信息分离。
无记录：显示“今天还没有记录”；快捷操作仍可用，不填示例统计值冒充真实数据。
离线：新增显示待同步；读取现有数据；保存状态不冒充云端已同步。此处仅模拟，实际本地落盘和同步策略待定义。
概况加载失败：局部显示重试，不阻断记录入口，不抹除记录列表。
任务进行中：首页恢复入口，AI 页继续；重复点击不能新建第二份同类任务。
身份/阶段缺失：真实实现须提示补齐，并保留允许无上下文完成的操作；本候选不实现缺失身份场景。
权限拒绝：任务页解释权限原因与重试/退出，不在首页首开请求麦克风相机；本候选未触发真实权限。
通知深链：若未来有通知能力，进入目标记录/任务，返回所属 Tab；当前需求不确认有消息中心或通知业务，不新增铃铛入口。
跨日/时区：生产实现按确定的账户或展示时区汇总“今天”，记录保留发生时区，需定义旅行/跨时区策略；演示固定2026-10-19、UTC+08:00，不声称已实现。
大字/键盘/小屏：优先让操作可达；四项导航保留文字；完整系统大字与移动键盘待后续原生/高保真验证。

7. 挑战者视角自审（作者自审，不冒称独立评审）
挑战：是否只给旧会话页加一条 Dock？处理：首次进入改为今日概况；对话移到独立目的地，快捷任务跨页进入。
挑战：“记录”和“记一笔”是否重复？处理：前者回顾，后者创建，使用不同文案和容器；多入口共用同一表单与事件。
挑战：妈妈被宝宝数据淹没？处理：首页两个对象并列分区；记录页保留独立妈妈分组，吸奶量不计入宝宝喂养量。
挑战：设备是否藏太深？结论：当前仅信息/同步查看，两步可达；异常首页直达；高频控制需求出现时重新评估。
挑战：多个分析任务能否互相覆盖？处理：未完成任务期间阻止切换成另一专项任务，提示先处理当前任务；不承诺后台并行。
挑战：今日数据是否制造完整照护错觉？处理：明确“已记录”；无数据和读失败分别表达，不推导健康结论。
剩余不确定：Tab 数量和频率尚未由实际用户行为验证；孕期/备孕首页、通知、跨时区和真实同步未完成。本候选用于确认职责和路径，非最终产品可用性结论。

8. 候选规范
灰阶 + 单一深绿操作色；正文15px；次级12–13px；卡片圆角16px；主容器间距20px；按钮最小44px。
组件：身份背景、对象分组摘要、快捷操作、事件行、条件提示、四项导航、模态表单、AI任务卡。
状态：默认 / hover / focus / selected / empty / error / offline / task-active。图标为文字占位，后续替换统一资产。
这是结构评审规范，不替代其他聊天里的最终视觉方向；用户仅确认了B+C偏好，尚未确认本具体候选。
